# FlowMind AI

A modern AI landing page built with React, TypeScript, and Vite.

## Features

- Responsive UI
- Framer Motion animations
- EmailJS contact form
- Dark/Light theme
- Modern component-based architecture

## Tech Stack

- React
- TypeScript
- Vite
- Framer Motion
- EmailJS
